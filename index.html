高校考试网
自动刷课助手

按章节顺序自动选课、静音播放、学时达标后先把进度存住再切下一节，自动翻页。切到后台、最小化，照样计时。

安装脚本 先装 Tampermonkey

点击「安装脚本」后，油猴会弹出安装页。若只看到一堆代码，说明还没装 Tampermonkey。

安装步骤

  1. 给浏览器装 Tampermonkey（油猴）扩展，Chrome / Edge / Firefox 均有。
  2. 回到本页，点 安装脚本，在弹出页点「安装」。
  3. 打开 高校考试网 → 我的课程，右下角会出现控制面板，自动开始。
按章节顺序选课
每次刷新先退回第 1 页，从 1.1 起找第一个状态不是「已完成」的课。数字排序，1.9 排在 1.10 前面。
达标先存进度
学时够了不立刻关窗口——先等站点的进度上报落地，再切下一节。不会出现「刷完又从头刷一遍」。
后台继续计时
切标签页、最小化、锁屏都不停。四层伪装 + 按真实秒数补偿，补的时间恒等于真实经过时间。
自动翻页
本页全部完成自动翻下一页，翻页后仍按章节号取第一个未完成的。
防卡死
计时不动就重开播放器；学时够了但站点不认，先等结算、再重刷确认，最多两次就跳过，不死磕一节。
面板可控
右下角面板：暂停、跳过、前台伪装开关、诊断信息、清空记录。

不上传任何数据。脚本是单文件、@grant none、不引用任何外部库，不联网、不读账号密码、不写 Cookie，所有状态只存在你自己浏览器的 localStorage 里。

使用前请知悉

脚本会代替你保持播放状态，这与站点的用户协议存在冲突，账号风险由使用者自行承担。它不会伪造学习记录——补出的秒数恒等于真实挂机时间，只是把「切到后台就停表」改回「照常计时」。

请勿用于商业转售，也请勿同时挂多个账号。站点改版可能导致脚本暂时失效，更新见仓库 Releases。
